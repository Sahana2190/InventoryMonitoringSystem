# AI-Assisted Development Evidence

## Project: Inventory Monitoring System

### 1. Purpose

AI assistance was used as a development aid to understand Python concepts, improve project documentation, review testing practices, and troubleshoot Git and GitHub workflow issues.

The project code was run and tested locally to verify application behavior.

### 2. Representative Prompts Used

The following prompts summarize the types of assistance requested during development:

1. **Python project structure:** Explain the purpose of `__init__.py` and how Python project files should be organized.
2. **Unit testing:** Help create and run meaningful unit tests for product logic, inventory calculations, and CSV file validation.
3. **Application verification:** Explain application output, stock alerts, test results, and exception handling.
4. **Git and GitHub:** Provide step-by-step guidance for initializing Git, committing files, configuring a remote repository, and pushing changes.
5. **Documentation:** Improve the README with the project objective, features, setup instructions, execution steps, sample output, and team credits.

### 3. Improvements Made With AI Assistance

- Improved understanding of Python package structure.
- Created and executed unit tests for important application functionality.
- Reviewed inventory status and stock alert behavior.
- Improved project documentation and README presentation.
- Learned Git commands and the process of publishing a project on GitHub.

### 4. Verification Performed

The following checks were performed locally:

- Executed the application using `python app.py`.
- Verified the displayed inventory summary and stock alerts.
- Ran `python -m unittest discover -s tests -v`.
- Confirmed that all 16 unit tests passed.
- Verified that the application generated the inventory summary, low-stock, and category reports.
- Checked that Git successfully committed and pushed the project and README updates to GitHub.

### 5. Responsible Use of AI

AI suggestions were used as development guidance. Application behavior and test results were checked locally. The evidence records the assistance used and the verification performed; it does not imply that every possible edge case has been tested.
